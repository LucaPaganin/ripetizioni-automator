# Programmazione didattica di Matematica - Classe 3T

## Formule chiave

- **Equazioni irrazionali (radicali pari e dispari):**
  $$\sqrt[n]{A(x)} = B(x)$$

- **Funzione valore assoluto:**
  $$|f(x)| = k \quad (k \ge 0)$$

- **Equazione della retta:**
  $$y = mx + q \quad \text{oppure} \quad ax + by + c = 0$$

- **Circonferenza nel piano cartesiano:**
  $$(x - x_0)^2 + (y - y_0)^2 = r^2 \quad \text{oppure} \quad x^2 + y^2 + ax + by + c = 0$$

- **Ellisse con centro nell'origine:**
  $$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

- **Iperbole con centro nell'origine:**
  $$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$

- **Proprietà dei logaritmi:**
  $$\log_a(b \cdot c) = \log_a b + \log_a c$$
  $$\log_a\left(\frac{b}{c}\right) = \log_a b - \log_a c$$
  $$\log_a(b^c) = c \cdot \log_a b$$

### Esercizi simili
- **Esercizio 1:** Risolvere la seguente equazione irrazionale:
  $$\sqrt{x + 5} = x - 1$$
  <details><summary>Soluzione</summary>
  Impostiamo le condizioni di esistenza e la positività del secondo membro:
  $$\begin{cases} x + 5 \ge 0 \\ x - 1 \ge 0 \\ x + 5 = (x - 1)^2 \end{cases} \implies \begin{cases} x \ge -5 \\ x \ge 1 \\ x + 5 = x^2 - 2x + 1 \end{cases}$$
  Risolviamo l'equazione di secondo grado:
  $$x^2 - 3x - 4 = 0 \implies (x - 4)(x + 1) = 0$$
  Le soluzioni sono $x = 4$ e $x = -1$. Verificando con le condizioni ($x \ge 1$), scartiamo $x = -1$.
  Risultato: $\boxed{x = 4}$
  </details>

- **Esercizio 2:** Determinare il dominio della seguente funzione:
  $$f(x) = \ln(3 - x) + \frac{1}{\sqrt{x + 2}}$$
  <details><summary>Soluzione</summary>
  Poniamo a sistema le condizioni per l'esistenza del logaritmo e del radicale al denominatore:
  $$\begin{cases} 3 - x > 0 \\ x + 2 > 0 \end{cases} \implies \begin{cases} x < 3 \\ x > -2 \end{cases}$$
  Il dominio è l'intervallo aperto $(-2, 3)$.
  Risultato: $\boxed{D = (-2, 3)}$
  </details>

- **Esercizio 3:** Trovare l'equazione della circonferenza passante per l'origine avente centro nel punto $C(2, -3)$.
  <details><summary>Soluzione</summary>
  Il raggio $r$ è la distanza tra il centro $C(2, -3)$ e l'origine $O(0, 0)$:
  $$r = \sqrt{(2 - 0)^2 + (-3 - 0)^2} = \sqrt{4 + 9} = \sqrt{13}$$
  L'equazione canonica della circonferenza è:
  $$(x - x_C)^2 + (y - y_C)^2 = r^2 \implies (x - 2)^2 + (y + 3)^2 = 13$$
  Sviluppando i calcoli:
  $$x^2 - 4x + 4 + y^2 + 6y + 9 = 13 \implies x^2 + y^2 - 4x + 6y = 0$$
  Risultato: $\boxed{x^2 + y^2 - 4x + 6y = 0}$
  </details>

### Flashcard
- **D:** Quali sono le condizioni da imporre per risolvere un'equazione irrazionale del tipo $\sqrt{A(x)} = B(x)$ con indice pari? — **R:** Si pone il sistema formato da $B(x) \ge 0$, $A(x) \ge 0$ e dall'equazione elevata a potenza $A(x) = [B(x)]^2$.
- **D:** Come si definisce una funzione iniettiva? — **R:** Una funzione si dice iniettiva se elementi distinti del dominio hanno immagini distinte nel codominio ($x_1 \neq x_2 \implies f(x_1) \neq f(x_2)$).
- **D:** Qual è l'equazione canonica di un'ellisse con i fuochi sull'asse $x$? — **R:** $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ con $a > b$.
- **D:** Qual è la proprietà dei logaritmi del quoziente? — **R:** $\log_a\left(\frac{b}{c}\right) = \log_a b - \log_a c$.
