# Geometria analitica: Ellisse e Funzioni con modulo

## Formule chiave

- **Equazione canonica dell'ellisse con $a > b$:**
  $$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

- **Vertici dell'ellisse:**
  $A(-a, 0)$, $C(a, 0)$, $B(0, -b)$, $D(0, b)$

- **Fascio di rette passante per un punto $P(x_0, y_0)$:**
  $$y - y_0 = m(x - x_0)$$

- **Condizione di tangenza:**
  Si sostituisce l'equazione del fascio nell'equazione della curva ottenendo un'equazione di secondo grado in $x$ (o $y$), e si impone che il discriminante sia nullo ($\Delta = 0$).

## Esercizio 91

**Testo:**
Considera l'ellisse di equazione $x^2 + 4y^2 = 4$. Tra le rette passanti per il vertice dell'ellisse di ascissa negativa, determina quelle che individuano sull'ellisse un segmento di misura $\frac{4\sqrt{17}}{5}$.

**Svolgimento:**

1. **Riduzione in forma canonica dell'ellisse:**
   Dividiamo l'equazione per $4$:
   $$\frac{x^2}{4} + \frac{y^2}{1} = 1$$
   Quindi $a^2 = 4 \implies a = 2$ e $b^2 = 1 \implies b = 1$.

2. **Individuazione dei vertici:**
   - Asse $x$: $y = 0 \implies \frac{x^2}{4} = 1 \implies x = \pm 2$. I punti sono $A(-2, 0)$ e $C(2, 0)$.
   - Asse $y$: $x = 0 \implies y^2 = 1 \implies y = \pm 1$. I punti sono $B(0, -1)$ e $D(0, 1)$.

   Il vertice con ascissa negativa è $A(-2, 0)$.

3. **Fascio di rette per $A(-2, 0)$:**
   L'equazione del fascio è:
   $$y - 0 = m(x - (-2)) \implies y = m(x + 2)$$

4. **Intersezione fascio-ellisse:**
   Mettiamo a sistema il fascio con l'ellisse $x^2 + 4y^2 = 4$:
   $$\begin{cases} y = m(x + 2) \\ x^2 + 4m^2(x + 2)^2 = 4 \end{cases}$$
   Sviluppando il quadrato:
   $$x^2 + 4m^2(x^2 + 4x + 4) - 4 = 0$$
   $$(1 + 4m^2)x^2 + 16m^2x + 16m^2 - 4 = 0$$

5. **Risoluzione rispetto a $x$:**
   Troviamo le ascisse dei punti d'intersezione $A$ ed $E$:
   $$x_{1,2} = \frac{-8m^2 \pm \sqrt{64m^4 - (16m^2 - 4)(1 + 4m^2)}}{1+4m^2} = \frac{-8m^2 \pm \sqrt{4}}{1 + 4m^2} = \frac{-8m^2 \pm 2}{1 + 4m^2}$$
   Quindi:
   $$x_1 = -2, \quad x_2 = \frac{2 - 8m^2}{1 + 4m^2} = \frac{2(1 - 4m^2)}{1 + 4m^2}$$

   La corrispondente ordinata del punto $E$ (l'altro punto d'intersezione oltre ad $A$) è:
   $$y_E = \frac{4m}{1 + 4m^2}$$
   Quindi il punto $E$ ha coordinate:
   $$E\left(\frac{2(1 - 4m^2)}{1 + 4m^2}, \frac{4m}{1 + 4m^2}\right)$$

6. **Imposizione della misura del segmento $AE$:**
   La distanza $AE$ è data da:
   $$\overline{AE} = \sqrt{\left(\frac{2(1 - 4m^2)}{1 + 4m^2} + 2\right)^2 + \left(\frac{4m}{1 + 4m^2}\right)^2} = \sqrt{\frac{16 + 16m^2}{(1 + 4m^2)^2}} = \frac{4\sqrt{1 + m^2}}{1 + 4m^2}$$
   Imponendo $\frac{4\sqrt{1 + m^2}}{1 + 4m^2} = \frac{4\sqrt{17}}{5}$ ed elevando al quadrato:
   $$25(1 + m^2) = 17(1 + 4m^2)^2$$
   Sviluppando e riordinando si ottiene l'equazione in $t = m^2$:
   $$272t^2 + 111t - 8 = 0$$
   Applicando la formula risolutiva ($\Delta = 111^2 + 4 \cdot 272 \cdot 8 = 145^2$) si trova:
   $$t = \frac{-111 \pm 145}{544} \implies t = \frac{1}{16} \ \lor\ t = -\frac{8}{17}$$
   Poiché $t = m^2 \ge 0$, solo $t = \frac{1}{16}$ è accettabile. Troviamo $m$:
   $$m = \pm \sqrt{\frac{1}{16}} = \pm \frac{1}{4}$$

7. **Conclusione:**
   Le equazioni delle rette (secanti) richieste sono:
   $$\boxed{y = \pm \frac{1}{4}(x + 2)}$$

## Esercizio 93

**Testo:**
Determina le rette tangenti all'ellisse di equazione $4x^2 + y^2 = 1$ e parallele alla retta di equazione $y = 2x$.

**Svolgimento:**

1. **Analisi dell'ellisse:**
   L'equazione data è $4x^2 + y^2 = 1$, che scritta in forma canonica diventa:
   $$\frac{x^2}{\left(\frac{1}{4}\right)} + \frac{y^2}{1} = 1$$
   Quindi $b^2 = 1$ e $a^2 = \frac{1}{4}$ (da cui $a = \frac{1}{2}$).

2. **Fascio di rette parallele:**
   La retta data ha coefficiente angolare $m = 2$. Il fascio di rette parallele ha equazione:
   $$r: y = 2x + q$$

3. **Condizione di tangenza:**
   Mettiamo a sistema il fascio con l'ellisse:
   $$\begin{cases} y = 2x + q \\ 4x^2 + y^2 = 1 \end{cases}$$
   Sostituendo $y$:
   $$4x^2 + (2x + q)^2 = 1$$
   $$4x^2 + 4x^2 + 4qx + q^2 - 1 = 0$$
   $$8x^2 + 4qx + (q^2 - 1) = 0$$

   Imponiamo la condizione di tangenza $\Delta = 0$:
   $$\frac{\Delta}{4} = (2q)^2 - 8(q^2 - 1) = 0$$
   $$4q^2 - 8q^2 + 8 = 0$$
   $$-4q^2 + 8 = 0 \implies 4q^2 = 8 \implies q^2 = 2 \implies q = \pm\sqrt{2}$$

4. **Conclusione:**
   Le equazioni delle rette tangenti sono:
   $$\boxed{y = 2x \pm \sqrt{2}}$$

## ⚠️ Errori da evitare

- Non considerare la limitazione geometrica o algebrica dei parametri (es. $t = m^2 \ge 0$).
- Dimenticare il doppio segno $\pm$ quando si estrae la radice quadrata di un parametro al quadrato ($q^2 = 2 \implies q = \pm\sqrt{2}$).
