# Equazioni con moduli e radicali

## Formule chiave

### Formula ridotta del $\Delta$ ($\Delta/4$)
Data un'equazione di secondo grado nella forma normale:
$$ax^2 + bx + c = 0$$

Il discriminante ridotto $\frac{\Delta}{4}$ si definisce come:
$$\frac{\Delta}{4} = \left(\frac{b}{2}\right)^2 - ac$$

Le soluzioni si calcolano con la formula:
$$x = \frac{-\frac{b}{2} \pm \sqrt{\frac{\Delta}{4}}}{a}$$

Se $a = 1$:
$$x = -\frac{b}{2} \pm \sqrt{\left(\frac{b}{2}\right)^2 - ac}$$

---

## Esercizio 1

Risolvere l'equazione con modulo:
$$x + 2|x + 1| - x^2 + |x| = 0$$

### Studio dei segni dei moduli:
- Argomento primo modulo: $x + 1 \ge 0 \implies x \ge -1$
- Argomento secondo modulo: $x \ge 0$

I punti di svolta sulla retta reale sono $x = -1$ e $x = 0$, che dividono l'asse in tre intervalli:

1. **Caso 1: $x \le -1$**
   Entrambi gli argomenti sono negativi: $|x+1| = -(x+1)$ e $|x| = -x$.
   L'equazione diventa:
   $$x - 2(x + 1) - x^2 - x = 0$$
   $$x - 2x - 2 - x^2 - x = 0$$
   $$-x^2 - 2x - 2 = 0 \implies x^2 + 2x + 2 = 0$$
   Calcoliamo il $\Delta/4$:
   $$\frac{\Delta}{4} = 1^2 - 1 \cdot (2) = 1 - 2 = -1 < 0 \implies \text{Nessuna soluzione reale}$$

2. **Caso 2: $-1 < x \le 0$**
   Il primo modulo è positivo ($x+1 \ge 0$), il secondo è negativo ($x < 0$).
   L'equazione diventa:
   $$x + 2(x + 1) - x^2 - x = 0$$
   $$x + 2x + 2 - x^2 - x = 0 \implies -x^2 + 2x + 2 = 0 \implies x^2 - 2x - 2 = 0$$
   Usiamo la formula ridotta:
   $$x = 1 \pm \sqrt{(-1)^2 - 1\cdot(-2)} = 1 \pm \sqrt{1 + 2} = 1 \pm \sqrt{3}$$
   Dobbiamo accettare solo le soluzioni tali che $-1 < x \le 0$:
   - $1 - \sqrt{3} \approx 1 - 1,73 = -0,73$ (Accettabile, poiché $-1 < -0,73 \le 0$)
   - $1 + \sqrt{3} \approx 2,73$ (Non accettabile)

   Soluzione del caso 2: $\boxed{x = 1 - \sqrt{3}}$

3. **Caso 3: $x > 0$**
   Entrambi gli argomenti sono positivi.
   L'equazione diventa:
   $$x + 2(x + 1) - x^2 + x = 0$$
   $$x + 2x + 2 - x^2 + x = 0 \implies -x^2 + 4x + 2 = 0 \implies x^2 - 4x - 2 = 0$$
   Usiamo la formula ridotta:
   $$x = 2 \pm \sqrt{(-2)^2 - 1\cdot(-2)} = 2 \pm \sqrt{4 + 2} = 2 \pm \sqrt{6}$$
   Dobbiamo accettare solo le soluzioni tali che $x > 0$:
   - $2 - \sqrt{6} \approx 2 - 2,45 = -0,45$ (Non accettabile, perché minore di $0$)
   - $2 + \sqrt{6} \approx 2 + 2,45 = 4,45$ (Accettabile)

   Soluzione del caso 3: $\boxed{x = 2 + \sqrt{6}}$

### Risultato complessivo:
$$\boxed{x = 1 - \sqrt{3} \quad \lor \quad x = 2 + \sqrt{6}}$$

### Riepilogo
Le equazioni con moduli si risolvono suddividendo il dominio in intervalli in base al segno degli argomenti dei moduli, impostando un sistema per ciascun intervallo e unendo infine le soluzioni accettabili. Per il calcolo delle equazioni di secondo grado con coefficiente del termine di primo grado pari, l'uso della formula ridotta $\Delta/4$ semplifica notevolmente i calcoli.

### Esercizi simili

1. Risolvi la seguente equazione con modulo:
   $$|x - 2| + x - |x + 1| = 3$$
   <details><summary>Soluzione</summary>
   Si dividono gli intervalli in base ai punti $x = -1$ e $x = 2$:
   - Per $x < -1$: $-(x - 2) + x - [-(x + 1)] = 3 \implies -x + 2 + x + x + 1 = 3 \implies x = 0$ (Non accettabile).
   - Per $-1 \le x < 2$: $-(x - 2) + x - (x + 1) = 3 \implies -x + 2 + x - x - 1 = 3 \implies -x + 1 = 3 \implies x = -2$ (Non accettabile).
   - Per $x \ge 2$: $(x - 2) + x - (x + 1) = 3 \implies x - 2 + x - x - 1 = 3 \implies x - 3 = 3 \implies x = 6$ (Accettabile).
   Soluzione: $\boxed{x = 6}$
   </details>

2. Risolvi l'equazione:
   $$x^2 - 3|x| + 2 = 0$$
   <details><summary>Soluzione</summary>
   Essendo $x^2 = |x|^2$, poniamo $t = |x| \ge 0$:
   $$t^2 - 3t + 2 = 0 \implies (t - 1)(t - 2) = 0 \implies t = 1 \lor t = 2$$
   Tornando a $x$:
   - $|x| = 1 \implies x = \pm 1$
   - $|x| = 2 \implies x = \pm 2$
   Soluzioni: $\boxed{x = -2, -1, 1, 2}$
   </details>

3. Trova le soluzioni dell'equazione:
   $$|2x - 1| = x + 2$$
   <details><summary>Soluzione</summary>
   Si imposta l'unione dei due sistemi:
   1. $\begin{cases} 2x - 1 \ge 0 \\ 2x - 1 = x + 2 \end{cases} \implies \begin{cases} x \ge \frac{1}{2} \\ x = 3 \end{cases} \implies x = 3$ (Accettabile)
   2. $\begin{cases} 2x - 1 < 0 \\ -(2x - 1) = x + 2 \end{cases} \implies \begin{cases} x < \frac{1}{2} \\ -2x + 1 = x + 2 \end{cases} \implies \begin{cases} x < \frac{1}{2} \\ 3x = -1 \end{cases} \implies x = -\frac{1}{3}$ (Accettabile)
   Soluzione: $\boxed{x = -\frac{1}{3} \lor x = 3}$
   </details>
